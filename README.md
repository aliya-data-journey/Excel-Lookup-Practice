
# Excel Lookup Practice

A practice project using a small employee dataset.

## What I used
- VLOOKUP, XLOOKUP, INDEX-MATCH, IFERROR
- SUMIF, AVERAGEIF, COUNTIF
- Pivot Table and Slicer

## Sheets
- Summary: department salary summary with chart
- Pivot_Summary: pivot table with slicer
- Employees: main data and bonus calculation
- Bonus_Table: lookup table
- Lookup_Practice: lookup examples
